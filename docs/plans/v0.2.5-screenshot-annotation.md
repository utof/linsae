  `simulatePressure`-defaults-true gotcha (spec §stroke.ts note).

### T1.3 `ink/svg.ts` — `serializeScene` / `parseScene`
- [ ] **Test first** `ink/svg.test.ts`:
  - **Round-trip** `parseScene(serializeScene(scene))` preserves `points`/`simulatePressure`/

    z-order (element array order). Text `height` is NOT asserted (re-measured).
  - **Tamper resistance:** take a serialized SVG, corrupt a `<path d="…">` to garbage, assert
    `parseScene` still reconstructs the stroke from `data-points` (geometry ignored — the XSS/

- [ ] Implement per spec §"Serialize / parse": serialize emits `viewBox="0 0 w h"`, one `<path>`

- [ ] **Test first** `AnnotateEditor.test.tsx` (RTL): mounts a modal over a frame with a toolbar
  (pen/text/eraser toggles + swatches + Done/Cancel). Cover, per spec §AnnotateEditor:

  - **pen**: a pointerdown→move→up sequence on the `<svg>` appends one `Stroke` to scene state;
