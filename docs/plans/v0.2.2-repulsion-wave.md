# Selectable Feed Entrance Animations — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the rolling-feed send entrance a pluggable strategy with three selectable
animations — `glide` (today's shipped scroll-glide), `flip`, `pbd` — chosen by a persisted user
preference (default `glide`), behind one clear per-file seam.

**Architecture:** A Feed-facing dispatcher hook reads the pref and runs the chosen strategy.
`glide` is `useAppendReveal` moved behind the seam (scroll-glide, unchanged). `flip`/`pbd` share a
per-row `--wy` transform "wave engine" (a Motion `frame.update` spring loop) and differ only by an
optional non-overlap projection. The virtualizer's append-follow is suppressed by passing
`anchorTo`/`followOnAppend` **into** `useVirtualizer` (not mutating its options after the hook) —
the spike proved this is the only place it takes effect on the append render.

**Tech Stack:** React 19 + React Compiler, `@tanstack/react-virtual` v3
(`anchorTo`/`followOnAppend`/`shouldAdjustScrollPositionOnItemSizeChange`/`isAtEnd`), `motion`
(`frame.update`/`cancelFrame`/`animate`), Vitest + RTL + happy-dom, Playwright-Electron harness.

**Spec:** `docs/specs/v0.2.2-repulsion-wave.md`
**Reference implementation (proven, port from here):** `src/renderer/src/dev/RevealPlayground.tsx`
(committed `5ba17cc`+`3eeabb7`) and its harness `scripts/wave-reveal.mjs`.

```ts
import { useEffect, useState } from 'react'
import type { FeedEntrance } from '../feed/entrance/types'

/**
 * Persisted feed-entrance-animation preference. Mirrors lib/clock-pref.ts exactly
 * (localStorage + a same-document custom event + a reactive hook): the DOM `storage`
 * event only fires in OTHER documents, so we dispatch our own on write.
 * @see src/renderer/src/lib/clock-pref.ts
 * @see docs/specs/v0.2.2-repulsion-wave.md §Decisions
 */
const KEY = 'linsae.feedEntrance'
const EVENT = 'linsae:feed-entrance'
const VALID = new Set<string>(['glide', 'flip', 'pbd'])

/** Read the preference. An unknown/legacy stored value falls back to 'glide' (never throws). */
export function getFeedEntrance(): FeedEntrance {
  const v = localStorage.getItem(KEY)
  return v && VALID.has(v) ? (v as FeedEntrance) : 'glide'
}

/** Persist + notify same-document subscribers. */
export function setFeedEntrance(v: FeedEntrance): void {
  localStorage.setItem(KEY, v)
  window.dispatchEvent(new Event(EVENT))
}

/** Reactive read — re-renders the caller when the pref changes. */
export function useFeedEntrance(): FeedEntrance {
  const [v, setV] = useState(getFeedEntrance)
  useEffect(() => {
    const handler = () => setV(getFeedEntrance())
    window.addEventListener(EVENT, handler)
    return () => window.removeEventListener(EVENT, handler)
  }, [])
  return v
}
```

```ts
import { useRef, useState } from 'react'
import { getFeedEntrance } from '../../lib/anim-pref'
import type { EntranceCtx, FeedEntrance } from './types'
import { useGlideReveal } from './glideReveal'

/**
 * Feed-facing dispatcher: picks the entrance strategy (per-send, from the pref) and exposes
 * `suppressFollow` so the Feed passes the correct anchorTo/followOnAppend INTO useVirtualizer.
 * @see docs/specs/v0.2.2-repulsion-wave.md §Architecture, §Guard
 */
export function useEntranceAnimation(
  ctx: Omit<EntranceCtx, 'setWaveSettling'> & { sendInFlight: boolean },
): { suppressFollow: boolean } {
  const [waveSettling, setWaveSettling] = useState(false)
  // Snapshot the pref per-send (read fresh; the append effects read .current).
  const entranceRef = useRef<FeedEntrance>(getFeedEntrance())
  entranceRef.current = getFeedEntrance()

  // Batch 1: glide always runs (it self-gates on append + reduced-motion + at-end).
  // Batch 2 (Task 9) routes flip/pbd to useWaveReveal and gates glide on entranceRef.
  useGlideReveal({
    virtualizer: ctx.virtualizer,
    scrollerEl: ctx.scrollerEl,
    notes: ctx.notes,
    revealingRef: ctx.revealingRef,
    setRevealing: ctx.setRevealing,
    suppressThumbResizeRef: ctx.suppressThumbResizeRef,
  })

  const suppressFollow = ctx.sendInFlight || waveSettling || ctx.revealingRef.current
  return { suppressFollow }
}
```

```ts
/**
 * One semi-implicit (symplectic) Euler step of a critically-ish damped spring pulling
 * `off` toward 0. `dtMs` is clamped to 32ms so a long frame can't explode a stiff spring.
 * @see src/renderer/src/dev/RevealPlayground.tsx (the proven loop)
 */
export function springStep(
  s: { off: number; vel: number },
  dtMs: number,
  stiffness: number,
  damping: number,
): { off: number; vel: number } {
  const dt = Math.min(dtMs, 32) / 1000
  const a = -stiffness * s.off - damping * s.vel
  const vel = s.vel + a * dt
  return { off: s.off + vel * dt, vel }
}
```

```ts
describe('projectNoOverlap', () => {
  // offsets are ordered TOP→BOTTOM; the last (newcomer) is the pinned anchor and is never moved.
  it('leaves an already non-overlapping stack unchanged', () => {
    expect(projectNoOverlap([0, 0, 50], 8)).toEqual([0, 0, 50])

    const out = projectNoOverlap([50, 10], 8)

  })
  it('propagates the shove upward across the stack', () => {
    const out = projectNoOverlap([90, 60, 30, 0], 8)
    for (let i = 1; i < out.length; i++) expect(out[i] - out[i - 1]).toBeGreaterThanOrEqual(-1e-9)
    expect(out[out.length - 1]).toBe(0) // anchor pinned
```

- [ ] **Step 2:** Run → FAIL. **Step 3: Implement** (from `RevealPlayground.tsx:242-264`; pure on
  offsets — the rest gaps already encode row heights, so only offset differences need constraining):

```ts
/**
 * Up-only, bottom→top non-overlap projection for the wave. `offsets` are the per-row `--wy`
 * offsets ordered TOP→BOTTOM; the last row (the newcomer) is the pinned anchor (only ever the
 * LOWER of a pair, so it is never pushed). For each adjacent pair the lower offset must be ≥ the
 * upper (rest positions already encode heights), so a negative gap pushes ONLY the upper up;
 * sweeping bottom→top, `passes` times, propagates the shove — the magnet impulse emerges from
 * the constraint. Returns a new array; does not mutate the input.
 * @see src/renderer/src/dev/RevealPlayground.tsx (the proven projection)
 * @see docs/specs/v0.2.2-repulsion-wave.md §Architecture
 */
export function projectNoOverlap(offsets: number[], passes: number): number[] {
  const out = offsets.slice()
  for (let it = 0; it < passes; it++) {
    for (let i = out.length - 2; i >= 0; i--) {
      const gap = out[i + 1] - out[i] // lower − upper, want ≥ 0
      if (gap < 0) out[i] += gap // push ONLY the upper up; the lower stays pinned
    }
  }
  return out
}
```
