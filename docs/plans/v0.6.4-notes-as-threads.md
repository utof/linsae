# v0.6.4 notes-as-threads — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make PDFs first-class media notes that persist in the feed with a chronological-only thread; make every note openable as a `comment-on` thread; and make media surfaces (PDF reader, YouTube player) detachable right-dock panes so the `feed|canvas` center can flip while the document stays open.

**Architecture:** No schema migration — reuse the `comment-on` slug-generic primitive, the `pdf_documents` metadata table, and the `source_kind`/`source_locator` columns. The structural change is relocating `ThreadView` from a full-body replacement into a sub-state of `<main>` so the docks stay mounted; everything else is composition (a `PdfFeedNote` card, a generic chronological thread + simple composer, an excerpt→child wiring, a player-placeholder move). The only public-surface change is an additive `PdfLocator` widening.

**Tech Stack:** Electron + React 19 + TS strict · better-sqlite3 (raw SQL) · @tanstack/react-query · zustand · Vitest + RTL + happy-dom · Playwright-Electron smoke.

**Spec:** `docs/specs/v0.6.4-notes-as-threads.md` (read it first). **Briefing for every task subagent:** read `CLAUDE.md` first; tools `mcp__codebase-memory-mcp__*` before Grep; `context7` for any library API; cite file:line. Run only the changed test file for TDD feedback (`pnpm vitest run <file>`), NOT the full suite — lefthook is the authoritative gate at commit. Never `--no-verify`.

```tsx
import { useState } from 'react'

/** Minimal thread composer: Enter posts a comment-on child; no media chrome.
 *  Why: the YouTube ThreadComposer (~405 lines) is media-specific; plain/PDF
 *  threads need only text-in. @see docs/specs/v0.6.4-notes-as-threads.md */
export function SimpleComposer({ onSubmit }: { onSubmit: (body: string) => void }) {
  const [body, setBody] = useState('')
  return (
    <textarea
      value={body}
      onChange={(e) => setBody(e.target.value)}
      onKeyDown={(e) => {
        if (e.key === 'Enter' && !e.shiftKey) {
          e.preventDefault()
          const t = body.trim()
          if (t) { onSubmit(t); setBody('') }
        }
      }}
      placeholder="add a note…"
      style={{ /* …v21 tokens, mirror Composer… */ }}
    />
  )
}
```

export function getSourceNoteByPdfId(db: DB, pdfId: string): Note | null {
  const row = db.prepare(
    `SELECT id, slug, body, type, created_at, updated_at, deleted_at, source_kind, source_locator
       FROM notes
      WHERE deleted_at IS NULL AND type='source' AND source_kind='pdf'
        AND json_extract(source_locator,'$.pdf_id') = ?
      LIMIT 1`,
  ).get(pdfId) as (Omit<Note,'source_locator'> & { source_locator: string|null }) | undefined
  if (!row) return null
  return { ...row, source_locator: row.source_locator ? JSON.parse(row.source_locator) : null }
}
